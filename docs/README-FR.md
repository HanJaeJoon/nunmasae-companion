# Nunmasae Companion

Un compagnon non officiel et sans spoilers, créé par des fans, pour le roman de fantasy coréen "The Bird That Drinks Tears" (눈물을 마시는 새). Il n'affiche les personnages, les lieux et les termes que jusqu'au tome que vous avez lu.

> [!NOTE]
> Les écrans de l'application sont uniquement en anglais et en coréen. Ce README a été traduit automatiquement avec Claude ; les corrections sont les bienvenues.

## Présentation

- Indiquez jusqu'où vous avez lu (tomes 1 à 4). L'application n'affiche que les personnages, peuples, lieux et termes apparus jusque-là et, dans chaque fiche, uniquement les faits révélés à ce stade.
- Les fiches et les faits des tomes que vous n'avez pas lus ne sont pas floutés : ils ne sont pas affichés du tout, si bien que même leur nombre reste caché.
- Les grands rebondissements du tome que vous lisez actuellement restent masqués sur l'écran de détail jusqu'à ce que vous appuyiez dessus.
- Écrans en anglais et en coréen. L'écran anglais affiche aussi les noms coréens pour que vous puissiez les rapprocher de l'original.
- Pas de publicité, pas de dons, pas de fonctions payantes, pas de connexion, pas de serveur. Les seules données enregistrées sur votre appareil sont votre progression de lecture et la langue choisie.
- Téléchargement : Google Play (bientôt disponible)

## Signaler une erreur

Les faits sont résumés à partir de sources secondaires, et non des livres eux-mêmes ; certains peuvent donc être faux ou rattachés au mauvais tome. Signalez-le-nous et nous corrigerons.

- Dans l'application : Settings (Paramètres) > "Report on GitHub" (Signaler sur GitHub) ou "Report by email" (Signaler par e-mail)
- [Ouvrez une issue GitHub](https://github.com/HanJaeJoon/nunmasae-companion/issues/new/choose) et choisissez un formulaire : fait erroné / révélé trop tôt (spoiler) / nom anglais
- Corrigez vous-même et envoyez une pull request : [CONTRIBUTING.md](CONTRIBUTING.md)

**Attention aux spoilers** : si le titre ou le texte de votre issue risque de gâcher la lecture de ceux qui n'ont pas fini, ajoutez `[Spoiler Book N]` sur la première ligne.

## Non officiel

Ceci est un projet de fans, sans lien avec l'auteur, les éditeurs (Golden Bough, HarperCollins) ni Krafton. Les noms, l'univers et les termes appartiennent à l'œuvre originale ; chaque phrase factuelle de l'application est un résumé original. Aucune citation des livres, aucune couverture, aucune illustration. Si un ayant droit le demande, nous retirons le contenu immédiatement.
