# 한국어 (ko-KR) - 번역

## 앱 이름 (30자)

눈마새 길잡이: 스포 없는 용어집

## 간단한 설명 (80자)

읽은 권까지만 보여 주는 인물, 종족, 장소, 용어 사전. 앞 내용을 미리 볼 걱정 없이 찾아보세요.

## 자세한 설명 (4,000자)

읽은 권까지만 보여 주는 스포일러 없는 용어집입니다. 어디까지 읽었는지 고르면 그때까지 등장한 인물, 종족, 장소, 용어만 보여 주고, 항목 안에서도 그 권까지 밝혀진 사실만 보여 줍니다. 아직 읽지 않은 부분은 흐리게 가리지 않고 아예 나타나지 않으므로 항목 개수로도 뒷이야기를 짐작할 수 없습니다.

눈마새 길잡이는 소설 "눈물을 마시는 새"의 비공식 팬 동반 앱입니다.

담긴 것
- 인물, 종족과 신, 장소, 용어 탭
- 모든 탭에서 이름 검색
- 항목마다 밝혀진 순서대로 정리한 사실
- 읽은 권(1~4권) 선택, 언제든 변경 가능
- 한국어판 권과 영문판 권의 대응 표시

현재 내용
1권부터 4권까지의 항목이 들어 있습니다. 내용은 계속 확인하며, 틀린 곳을 알려 주시면 바로 고칩니다.

지원 언어
영어, 한국어 (설정에서 전환)

개인정보와 비용
- 인터넷 연결 없이 동작합니다. 계정과 서버가 없습니다.
- 광고, 인앱 결제, 후원이 없습니다.
- 기기에 저장하는 것은 읽은 권과 언어 선택뿐입니다.

비공식 안내
팬이 만든 앱이며 작가, 출판사 등 권리자와 관계가 없고 승인받지 않았습니다. 모든 설명은 이 앱을 위해 직접 쓴 짧은 요약이며 원작의 문장이나 그림을 싣지 않습니다. 인물, 장소, 용어의 이름은 원작에 속합니다.
