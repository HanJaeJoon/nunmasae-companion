# 눈마새 동반 앱 데이터 초안 (1~4권)

사용법: 틀린 문장은 고치고, 빼야 할 줄은 지운다. 문장은 전부 새로 쓴 요약이고 책 원문 대조가 아니라 2차 출처 기준이다.

- 범위: 구판 1~4권(양장본 1~18장). 재료는 `docs/design.md`, 이종범 설명회 자막, 웹 조사다.
- 2026-11-15 조사로 1~2권 권 번호를 채웠고, 2026-11-16 조사로 1~4권까지 넓혔다. 11/16 출처 8종: 오디오북 1장, 스토리캠프 후반부 설명회, 나무위키, 브릿G 회차 목록, 20주년판 삽화 캡션, 네이버/티스토리 독후감, 포스타입 연표, 위키백과/디시.
- 교차 검증: 쪽수/장이 붙은 근거(블로그 쪽수 발췌, 연표, 삽화, 오디오북) > 브릿G 회차 위치(1권 1~66화, 2권 67~135화, 3권 136~187화, 4권 188~233화) > 권별 독후감 > 설명회 > 나무위키 순으로 믿는다. 독립 출처 둘이 같은 권이면 확정, 어긋나면 늦은 권.
- 줄 형식: `- 사실: 문장. (권: N) [출처: ...]`. `기존` 은 11/15 조사에서 이미 정한 줄이다. `- 메모:` 는 남은 의문과 미확정 표기만 적는다.
- `(권: N)`: 확정. `(권: N?)`: 추정(출처가 하나뿐이거나 약함). `(권: )`: 근거 없음, 앱에 넣지 않는다.
- `?` 줄도 앱에는 그 권으로 들어가고, 틀리면 사용자 피드백으로 고친다 (2026-11-16 결정).
- 줄별 근거 URL 은 `docs/data-draft-evidence.json` 에 있으며 11/15 조사분까지만 있다.
- 표기는 나무위키 기준이다 (쥬타기, 바우 머리돌, 극연왕, 파름 평원, 시모그라쥬, 쇼자인테쉬크톨 등).
