# 눈마새 동반 앱 데이터 초안 (1~2권)

사용법: 각 사실 줄 끝의 `(권: )` 에 그 사실이 밝혀지는 권 번호(1~4)를 적는다. 틀린 문장은 고치고, 빼야 할 줄은 지운다. `?` 는 작성자가 확신 못 한 것.

- 범위: 구판 1~2권(양장본 1~10장). 3~4권 첫 등장 항목과 3~4권에서 밝혀지는 정체/음모는 넣지 않았다.
- 재료: `docs/design.md`, 이종범 설명회 자막 분석, 나무위키(사실 확인용). 문장은 전부 새로 썼다.
- 표기는 나무위키 기준으로 맞췄다 (쥬타기, 바우 머리돌, 극연왕, 무룬 강, 군령자, 제왕병자, 쇼자인테쉬크톨 등).

## 종족

- 사실: 하늘을 떠다니는 거대한 생물로, 다른 생물과 같은 부류로 여겨지지 않는다. (권: 1?)
