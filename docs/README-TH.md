# Nunmasae Companion

แอปคู่หูสำหรับแฟน ๆ แบบไม่เป็นทางการและไม่มีสปอยล์ สำหรับนิยายแฟนตาซีเกาหลี "The Bird That Drinks Tears" (눈물을 마시는 새) แอปจะแสดงตัวละคร สถานที่ และคำศัพท์ จนถึงเล่มที่คุณอ่านแล้วเท่านั้น

> [!NOTE]
> หน้าจอของแอปมีเฉพาะภาษาอังกฤษและภาษาเกาหลีเท่านั้น README นี้แปลด้วยเครื่องโดยใช้ Claude ยินดีรับคำแนะนำและการแก้ไขเสมอ

## แอปนี้คืออะไร

- เลือกว่าคุณอ่านถึงเล่มไหนแล้ว (เล่ม 1 ถึง 4) แอปจะแสดงเฉพาะตัวละคร เผ่าพันธุ์ สถานที่ และคำศัพท์ที่ปรากฏแล้วจนถึงตอนนั้น และในแต่ละรายการก็แสดงเฉพาะข้อมูลที่เปิดเผยแล้วจนถึงตอนนั้นเท่านั้น
- รายการและข้อมูลจากเล่มที่คุณยังไม่ได้อ่านจะไม่ได้ถูกเบลอไว้ แต่จะไม่ถูกแสดงเลย แม้แต่จำนวนก็ยังถูกซ่อนไว้
- จุดหักมุมสำคัญในเล่มที่คุณกำลังอ่านอยู่จะถูกปิดไว้ในหน้ารายละเอียดจนกว่าคุณจะแตะเพื่อเปิดดู
- มีหน้าจอภาษาอังกฤษและภาษาเกาหลี หน้าจอภาษาอังกฤษจะแสดงชื่อภาษาเกาหลีด้วย เพื่อให้คุณเทียบกับต้นฉบับได้
- ไม่มีโฆษณา ไม่มีการรับบริจาค ไม่มีฟีเจอร์แบบเสียเงิน ไม่ต้องล็อกอิน ไม่มีเซิร์ฟเวอร์ สิ่งเดียวที่เก็บไว้ในอุปกรณ์ของคุณคือความคืบหน้าในการอ่านและภาษาที่เลือก
- ดาวน์โหลด: Google Play (เร็ว ๆ นี้)

## แจ้งข้อผิดพลาด

ข้อมูลในแอปสรุปมาจากแหล่งข้อมูลทุติยภูมิ ไม่ได้มาจากตัวหนังสือโดยตรง จึงอาจมีบางส่วนที่ผิดหรือถูกจัดไว้ผิดเล่ม แจ้งเรามาได้ แล้วเราจะแก้ไขให้

- ในแอป: "Settings" (การตั้งค่า) > "Report on GitHub" (แจ้งผ่าน GitHub) หรือ "Report by email" (แจ้งทางอีเมล)
- [เปิด issue บน GitHub](https://github.com/HanJaeJoon/nunmasae-companion/issues/new/choose) แล้วเลือกแบบฟอร์ม: ข้อมูลผิด / เปิดเผยเร็วเกินไป (สปอยล์) / ชื่อภาษาอังกฤษ
- แก้ไขเองแล้วส่ง pull request: [CONTRIBUTING.md](CONTRIBUTING.md)

**คำเตือนเรื่องสปอยล์**: หากหัวข้อหรือเนื้อหาของ issue อาจสปอยล์ผู้อ่านที่ยังอ่านไม่จบ ให้ใส่ `[Spoiler Book N]` ไว้ที่บรรทัดแรก

## ไม่เป็นทางการ

นี่คือโปรเจกต์ของแฟน ๆ ไม่มีส่วนเกี่ยวข้องกับผู้เขียน สำนักพิมพ์ (Golden Bough, HarperCollins) หรือ Krafton ชื่อ โลกในเรื่อง และคำศัพท์เป็นของผลงานต้นฉบับ ส่วนประโยคข้อมูลทุกประโยคในแอปเป็นบทสรุปที่เขียนขึ้นใหม่ทั้งหมด ไม่มีการยกข้อความจากหนังสือ ไม่มีปก และไม่มีภาพประกอบ หากเจ้าของลิขสิทธิ์ร้องขอ เราจะนำออกทันที
